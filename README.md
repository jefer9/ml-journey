# ml-journey

aplicado. Empezó el 10 de septiembre de 2026.

Vengo de Python/Django, Postgres, Docker y despliegue en VPS. Lo que me falta
es la capa de modelos, así que estoy construyéndola en público: notas,
proyectos con datos reales de mis propios negocios, y todo lo que rompo en el
camino.
