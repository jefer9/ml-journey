# Notebooks

Borradores: acá se experimenta, no se entrega. Un notebook sirve para ver qué
hace una cosa; lo que entendiste va a `notas/conceptos/`, y lo que construiste
va a `proyectos/`.

Nombre: `NN-tema.ipynb` → `01-broadcasting.ipynb`, `02-vectorizado-vs-bucle.ipynb`.

Antes de commitear, **Kernel → Restart & Clear Output**: un diff de notebook con
salidas incrustadas es ilegible.
