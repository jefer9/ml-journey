# Datos

Nada de acá se sube, salvo `datos/ejemplo/*.csv`.

- `datos/` → crudos, reales, del negocio. **Nunca** al repo. Es un repo público.
- `datos/ejemplo/` → muestras chicas y anonimizadas, para que alguien que clone
  el repo pueda correr el código. Sin nombres de clientes, sin cédulas, sin
  teléfonos; los montos, escalados o recortados.

Antes de meter un CSV en `ejemplo/`, abrilo y mirá las columnas una por una.
"Creí que estaba anonimizado" ya pasó en repos más serios que este.
