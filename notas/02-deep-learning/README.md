# 02 — Deep learning

**PyTorch, no TensorFlow.**

**Fuentes:**
- fast.ai — *Practical Deep Learning for Coders* (top-down: primero funciona,
  después entendés por qué)
- Andrej Karpathy — *Neural Networks: Zero to Hero* (construir un GPT chico
  desde cero). Es el recurso que más rendimiento tiene de toda la ruta.

**Recorrido:** perceptrón → red multicapa → backprop (hacelo a mano una vez,
con dos neuronas, una sola vez) → embeddings → CNN rápido → atención →
transformers.
