## La analogía

Un vector es como una fila de una tabla.

Se parece a una fila en excel, o postgres, pero la fila no tiene la
caracteriztica de cada posicion.

## Por qué existe

El problema que resuelve es que el procesamiento de los datos es muchos mas
rapido, mientras en python normal es menos eficiente.

## Cómo funciona

NumPy funciona ordenando los números juntos en la memoria como una cinta transportadora

## Cuándo NO aplica

Datos mezclados, bases de datos vivas

## Cómo se ve en código

```python
vector = [5, 4, 3, 2, 1]
```
