# 01 — ML clásico

**Libro ancla:** *Hands-On Machine Learning with Scikit-Learn, Keras &
TensorFlow* — Aurélien Géron. Solo la primera parte (scikit-learn).

Los algoritmos son la parte fácil y la que menos se pregunta en entrevista.
Lo que te contratan por saber es esto:

- Cómo partir los datos y por qué el split aleatorio no sirve para series
  temporales
- Data leakage: la forma más común de tener un modelo excelente y un desastre
  en producción
- Elegir la métrica correcta, y saber defender la elección
- Qué hacer con clases desbalanceadas
- Baseline antes que modelo. Siempre.
